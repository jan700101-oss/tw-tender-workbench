# 標案工務台

臺灣政府標案搜尋網站:每日同步政府電子採購網公開資料,提供比官方網站好用的搜尋、篩選與收藏。

網站:https://jan700101-oss.github.io/tw-tender-workbench/

## 架構

```
政府電子採購網公開半月檔 XML(資料集下載頁,約 36 個月 × 每月 2 檔)
        │  GitHub Actions 每日 08:30 / 18:30(台北時間)自動執行
        ▼
scripts/sync.mjs  下載 → 解析 → 驗證 → 產出
        ▼
docs/data/        index.json(同步狀態)+ tenders-YYYY-MM.json(月分片資料)
        ▼
docs/             靜態網站(GitHub Pages),依查詢範圍延遲載入月份資料
```

## 資料誠信原則(經真實資料驗證的欄位語意)

- **公告期間**:官方檔名 `tender_YYYYMM01.xml` = 該月 1–15 日、`…02.xml` = 16 日–月底(半月檔)。
  XML 內沒有精確公告日,網站顯示「公告期間」而非假的公告日。
- **截止投標日**:官方 `TENDER_SPDT` 欄位;缺漏時明確顯示「截止日未提供」。
- **地區**:官方 XML 無地區欄位,由機關名稱與案名文字**推定**,介面標示「(推定)」。
- **涵蓋範圍**:此公開資料集為官方提供之**部分標案**(每半月約 100–340 筆),並非
  政府電子採購網全部公告;網站頁尾如實標示。
- 同一案(機關+案號+案名)出現在多個半月檔時,保留最新期間版本。
- 每筆附「官方查詢」與「來源檔」連結,可回政府正式來源核對。
- 同步失敗時保留上一版資料並顯示警示;資料超過 2 天未更新也會警示。

## 功能

- 關鍵字搜尋案名/案號/機關(空白分隔 = AND,`-詞` = 排除)
- 篩選:類別(工程/財物/勞務)、招標方式、地區(推定)、機關、公告期間(近 3/6/12 個月、全部約 3 年、自訂)
- 排序:公告期間或截止日(含剩餘天數,3 天內標紅)
- 收藏標案、儲存常用搜尋條件(保存於瀏覽器 localStorage,重新整理不消失)
- 預設載入近 3 個月,加大範圍時才下載其他月份,手機也能快速開啟

## 同步排程與手動執行

排程定義於 `.github/workflows/update-tenders.yml`,每日兩次;近 25 天內的半月檔
每次重抓(官方半月檔在期間內會持續增筆),歷史檔只抓一次。

手動執行(任何有 Node.js 20+ 的電腦):

```
node scripts/sync.mjs            # 正式同步(需可連線 web.pcc.gov.tw)
node scripts/sync.mjs --discover # 額外輸出欄位樣本與官方資料集描述
git add docs/data && git commit -m "更新標案資料" && git push
```
