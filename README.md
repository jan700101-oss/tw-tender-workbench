# 標案快搜

以行政院公共工程委員會政府電子採購網公開 XML 建立的輕量標案搜尋網站。

## 資料更新

```powershell
node scripts/sync-pcc-data.mjs
node scripts/check-data.mjs
```

預設同步近 30 天完整公告資料。GitHub Actions 每日自動執行；同步失敗時不會覆蓋上一版資料。

## 本機預覽

在專案根目錄啟動任一靜態網站伺服器，網站根目錄使用 `docs/`。不可直接雙擊 HTML，因瀏覽器不允許該方式載入 JSON。

## 資料欄位限制

本站透過 openfunltd 維護的標案資料 API，逐日收錄政府電子採購網公告，包含招標、決標、無法決標、公開取得、公開徵求及公開閱覽。詳細資料與更正公告以政府電子採購網為準。
