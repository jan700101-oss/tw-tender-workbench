使用原則

本清單依公共工程常見流程與工程會制度整理；個案仍以契約、招標文件、監造計畫及機關指定表單為準。系統不會替未確認資料補值。

PROJECT

工程專案

JSON 只供本系統備份進度，不是公共工程正式文件。 正式文件仍保留 PDF、Word／ODT、Excel／ODS、PCCES XML、TPA、CAD／BIM 等原始格式。JSON 備份含附件清單但不含檔案本體。

工程基本資料是共用主表，只填一次。 工程名稱、機關、案號、金額、日期、負責人與監造修改後，7 階段預填文書、Word 與列印資料包會同步使用；已人工修改的文件不會被覆蓋。

PDF / DWG DOCUMENT INTAKE

PDF／DWG 圖說包自動整理

只在此裝置分析
圖說
把建築師 PDF 或整包 DWG 丟到這裡

PDF 會讀取頁面文字與來源頁碼；多份 DWG 會依檔名與版本辨識平面、剖面、拆除、詳圖，整理到施工前、中、完工／竣工。

文件不會上傳公開網站。 PDF 解析、DWG 檔頭辨識、初步分類與保存都在目前瀏覽器內進行。手機／瀏覽器不會假裝讀懂 DWG 內部圖元、尺寸及文字；要做完整內容分析，請另附建築師出圖 PDF 或在桌面版使用 AutoCAD 解析。

一鍵完成：分析後按「一鍵建立並列印」，系統會建立文書追蹤、圖說目錄、施工前中後重點、缺漏清單及列印封面；有出圖 PDF 時，資料包會提供原圖列印連結，保留圖面線條與原尺寸比例。
