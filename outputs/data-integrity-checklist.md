# 資料誠信檢查清單

每次新增或更新標案資料，都必須檢查以下項目。

## 官方來源

- 單案 URL 是否存在。
- 單案 URL 是否能回到政府電子採購網該案頁面。
- URL 中的 `pk` 或 `pkPmsMain` 是否與此案唯一對應。
- 案名是否與官方頁一致。
- 機關是否與官方頁一致。
- 案號是否與官方頁一致。
- 預算、截止日、押標金是否與官方頁一致。

## 附件與投標須知

- 是否取得附件清單。
- 是否標示投標須知、標價清單、契約草案、施工規範、圖說、空白表單。
- 是否記錄附件版本與更正公告。
- 是否有解析來源頁碼、條文或段落。
- 未解析附件時，前台是否明確顯示待解析。

## AI 輸出

- 每個重點是否能回到來源。
- 不確定內容是否標示需人工確認。
- 推測、範例、正式資料是否分開。
- 是否避免用「已完成」描述尚未驗證的功能。

## 前台顯示

- 未核對資料不得顯示官方直達。
- 官方 URL 衝突時需自動關閉直達。
- 使用者可以看見目前資料狀態：已核對、待核對、待解析、需人工確認。
- 不能用假數量或假資料讓使用者誤以為是正式全量資料。
